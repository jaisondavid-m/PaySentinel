# 🛡️ PaySentinel Client — React + Tailwind CSS v4 Frontend

PaySentinel frontend interface built with **React 18**, **Tailwind CSS v4**, **Vite**, and **Lucide React** icons.

For full project architecture, backend documentation, and security audit scorecard, please see the primary repository [README.md](../README.md).

## 🚀 Running Locally

```bash
npm install
npm run dev
```

The app will run at `http://localhost:5173`.
